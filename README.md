Electricity Bill Management System

Project Description

This is a simple C programming project that calculates an electricity bill based on the number of units consumed.

Features

- Accepts electricity units as input.
- Calculates the bill based on sample unit rates.
- Displays the total electricity bill.
- Checks for invalid negative input.

Technologies Used

- Programming Language: C
- Platform: GitHub

How to Run

1. Download the "electricity_bill.c" file.
2. Open it in a C compiler.
3. Compile and run the program.
4. Enter the electricity units when prompted.

Note

The electricity rates used in this project are sample rates for educational purposes only.
